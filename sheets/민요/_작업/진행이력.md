## 작업 순서 (곡당)

1. 판독용 이미지가 없으면 먼저 만든다 (저장소 밖 `D:\pan`, 커밋하지 않음):
   `python sheets/민요/_작업/도구/prep_crops.py D:\pan`
   → `f1_07_RT.png` 등 4분할 + `map.txt`(키 → 원본 파일 → tsv 이름)
2. RT → RB → LT → LB 순서로 **한 장씩** 읽는다. 여러 장을 한 번에 읽으면 "2000 pixels" 크기 제한 오류로 세션이 멈춘다. `_full.png`(2480×3507)은 읽지 않는다.
3. TSV를 작성한다. 본문 행 수는 반드시 줄수 × 행수.
4. build로 검증한다: `python sheets/민요/_작업/도구/run_build.py D:\build_out.txt` → 로그에서 `DONE`, `팔레트 외`, `CSV 검증 오류`를 확인한다.
5. 팔레트 외 글자가 `?` 말고도 있으면 다시 판독한다.

## 판독 규칙 메모 (규격에 더해 지금까지 정한 것)

- 16정간 양식은 번호 2개가 한 칸 → 칸 위쪽 = 홀수, 아래쪽 = 짝수 정간. 율명이 세 개 쌓이면 위 둘 = 홀수, 마지막 = 짝수. 가사는 해당 율명을 따라간다.
- 12정간(중모리 등)은 정간마다 칸이 있음 → 3/4, 12.
- 가사 칸은 율명 줄의 바로 오른쪽에 있다.
- 인쇄된 줄이 비어 있어도 번호는 원본 그대로 둔다(빈 정간도 행으로 적는다).
- 요성 물결선, 작은 ▼ 표시, 율명 옆 `))` 곡선은 기호표에 없으므로 생략하고 #메모에 적는다. `^`는 율명 뒤에 붙인다(`無^`).
- #메모에 "근사", "가까운", "자진모리"가 들어가면 build가 '박자 근사'로 분류하니, 실제로 박자가 근사일 때만 쓴다.
- 이름이 같은 파일: `f1_25 창부 타령.jpg`와 `f1_26 창부 타령.png`가 둘 다 `1_창부 타령.tsv`로 매핑된다. 저장할 때 `1_창부 타령.jpg.tsv`처럼 구분할 것(아직 미처리).

## 환경 문제 (Windows, 이 PC 기준)

- 셸 도구에서 python을 직접 실행하면 가끔 0xc0000005로 죽는다. 그럴 때는 `Start-Process -NoNewWindow -Wait`로 띄우는 ps1을 통해 실행하고, 결과는 로그 파일로 확인한다.
- 스크립트에 한글 파일명을 직접 쓰지 않는다(코드포인트 오타로 실패한 적이 있다. 댕 = U+B315). `os.listdir` 결과만 쓴다.
- python 경로는 PC마다 다르다. 이 PC는 `C:\Users\infomania\AppData\Local\Programs\Python\Python312\python.exe`이며, Pillow가 필요하다.
