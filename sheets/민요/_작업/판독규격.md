# 민요채보 판독 규격 (TSV v2)

이미지 1장 = TSV 1개. 저장 위치: `sheets/민요/_작업/tsv/`
파일명: `{폴더번호}_{이미지 파일명에서 확장자 뺀 것}.tsv`  예) `2_창부 타령-1.tsv`, `1_이미지 (28).tsv`
인코딩: UTF-8 (BOM 없음), 줄바꿈 LF, 구분자 TAB.

## 1. 머리 정보 (#으로 시작, 순서 무관, 모르면 비움)

```
#제목	풍년가               ← 이미지에 쓰인 곡명(없으면 파일명 기준)
#부제	굿거리               ← 장단·버전 표기 (굿거리, 멜로디버전, 1절 …)
#키	C#                   ← "C#키", "C# key" 등
#쪽	197                  ← 인쇄된 쪽 번호
#박자	3/4                  ← 아래 2절 규칙
#행수	12                   ← 한 줄(세로 열)의 정간 수
#줄수	8                    ← 율명 줄(세로 열) 수, 오른쪽부터 1
#원본	민요채보-1/풍년가.png
#이어짐	                     ← 다른 이미지의 다음 장이면 그 TSV 파일명. 예) 1_창부 타령.tsv
#메모	                     ← 판독자 메모(이미지 전체에 관한 것)
```

## 2. 박자/행수 규칙 (앱이 지원하는 것만)

| 이미지의 한 줄 | #박자 | #행수 |
|---|---|---|
| 12정간, 굵은 선이 3칸마다 (가장 흔함) | 3/4 | 12 |
| 16정간, 굵은 선이 4칸마다 | 4/4 | 16 |
| 16정간(번호 1~16), 굵은 선이 2칸마다 | 2/4 | 16 |
| 20정간 (6-4-4-6) | 정악 | 20 |
| 그 밖 | 가장 가까운 것 + #메모에 실제 구조 |

- 한 칸이 번호 2개(예: 1·2)에 걸쳐 가로선 없이 합쳐져 있으면: 칸 위쪽 절반 내용 → 홀수 행, 아래쪽 절반 → 짝수 행으로 나눈다.
- 한 이미지의 줄이 10을 넘으면 #메모에 적고 11줄 이후도 그대로 번호를 이어서 적는다.

## 3. 본문 (머리 정보 다음 줄에 헤더, 내용이 있는 정간만)

```
줄	정간	율명	가사	비고
1	1	姑	풍
1	2	·
1	5	―|南
1	8	仲|姑
```

- 줄: 오른쪽 첫 율명 줄 = 1. 왼쪽으로 갈수록 증가.
- 정간: 위 = 1.
- 율명 칸: 정간 안에 위→아래로 쓰인 순서대로, 줄이 바뀌면 `|` 로 구분. 같은 높이에 나란히 쓴 두 글자는 붙여 쓴다(`南南`).
  - 율명은 아래 60자만 쓴다. 삼수변(氵)이 붙으면 청성, 사람인변(亻)이 붙으면 배(하) 옥타브.

```
중청 ㈜ 㶂 𣴘 㳲 㴺 㵈 㴢 㶙 㵉 㴣 㵜 㶃 㶝
청(氵) 潢 汏 汰 浹 㴌 㳞 㶋 淋 洟 湳 潕 㶐
중     黃 大 太 夾 姑 仲 㽔 林 夷 南 無 應
배(亻) 僙 㐲 㑀 俠 㑬 㑖 𠐭 㑣 侇 㑲 㒇 㒣
배배   㣴 㣕 㣖 㣣 㣨 㣡 㣸 㣩 𢓡 㣮 㣳 㣹
(순서: 黃 大 太 夾 姑 仲 㽔 林 夷 南 無 應)
```
    자주 나오는 것: 潢=氵黃(청황), 汰=氵太, 㴌=氵姑(청고), 㳞=氵仲(청중), 淋=氵林, 湳=氵南, 潕=氵無, 僙=亻黃, 㑲=亻南, 㒇=亻無, 㑣=亻林, 㑖=亻仲.
  - 기호는 아래 대표 글자만 쓴다(ASCII - . : < / o 금지).

| 이미지 | 대표 글자 |
|---|---|
| 짧은 가로선 - (연음) | `―` |
| 세모 △ (쉼) | `△` |
| 점 · | `·` |
| 동그라미 ○ | `○` |
| 두 점 : | `⁚` |
| 정간 경계의 < 표시 | `‹` (경계 바로 위 정간의 마지막에) |
| 율명 앞 사선 / | `／` |
| 체크 ✓, ^ 등 그 밖 | 가장 비슷한 것: `^` `ﾉ` `И` `⌝` `⌞` `⊏` `⊔` `ㅋ` `է` 중 고르고 비고에 설명 |

  - 못 읽는 글자는 `?` 로 적고 비고에 모양을 설명한다.
- 가사: 율명 줄 바로 오른쪽의 가사 칸에서, 해당 정간 높이에서 시작하는 글자들. 한 정간에 여러 글자면 붙여 쓴다(`씨구나`). 가사 칸이 없거나 비면 비움.
- 비고: 판독이 불확실할 때만. 짧게 (`㴌 확실치 않음`, `가사 절/얼?`). 비고가 있으면 검수 엑셀에서 노란 칸이 된다.
- 율명·가사가 모두 빈 정간도 **반드시 한 행으로 적는다** (`3	7			`). 즉 본문 행 수 = 줄수 × 행수. 빠뜨린 정간이 없는지 이것으로 검사한다.
- "머리 정보 위주로 기록", "전체 불확실" 같은 포기는 금지. 아무리 빽빽해도 정간마다 가장 그럴듯한 판독을 적고, 정말 모르겠는 글자만 `?`.
- 비고는 그 칸에 대한 구체적 내용만(`亻南? 侑처럼 보임`). 모든 칸에 "불확실"을 붙이지 않는다.

## 3-1. 손글씨 글자 구별 (자주 틀리는 것)

| 손글씨 모양 | 바른 글자 | 틀리기 쉬운 오답 |
|---|---|---|
| 亻 + 南 (侑·俉·偹처럼 보임) | `㑲` (배남려) | 俉 侑 |
| 亻 + 無 (僬·儛처럼 보임) | `㒇` (배무역) | 僬 |
| 亻 + 黃 (僙·儣처럼 보임) | `僙` (배황종) | 儣 |
| 亻 + 林 | `㑣` | 休 |
| 亻 + 仲 | `㑖` | 仲 |
| 氵 + 仲 (沖·神처럼 보임) | `㳞` (청중려) | 沖 神 |
| 氵 + 姑 (湖·沽처럼 보임) | `㴌` (청고선) | 湖 沽 |
| 氵 + 南 | `湳` | 渹 |
| 氵 + 黃 | `潢` | 潢 맞음 |
| 氵 + 太 | `汰` | 汏는 氵大 |
| 氵 + 林 | `淋` | |
| 氵 + 無 | `潕` | |
| 女 + 古 (끝이 흘려 古처럼) | `姑` | 古 |
| 仲 (亻+中, 율명 칸에서는 거의 항상 중성 仲) | `仲` | 中 |
| 南 흘림 (内·冂 안에 十) | `南` | 内 |

변이 사람인변인지(배성) 삼수변인지(청성) 없는지(중성)를 가장 먼저 본다. 같은 가락이 반복되는 곳의 같은 음은 같은 글자로 적는다.

## 4. 기준 예시

`sheets/민요/_작업/tsv/1_풍년가.tsv` (원본 `sheets/민요/원본/민요채보-1/풍년가.png`)를 반드시 먼저 이미지와 비교해 보고 같은 방식으로 적는다.
