# 대금율보 → 정간보 만들기 CSV 추출 설계서

대금율보 1·2권 PDF 를 **곡 1개 = CSV 1개**(정간보 CSV v2)로 바꿔, 앱 "정간보 만들기" 화면의 시트 목록(`sheets-index.json`)에서 불러올 수 있게 한다.
민요채보 파이프라인(`sheets/민요/_작업`, `판독규격.md`)을 그대로 재사용하고, 이 책에 필요한 **쪽 → 곡 분할 단계**와 판독 규칙만 더한다.

## 1. 원본 분석 (2026-10-10 확인)

| 항목 | 대금율보 1.pdf | 대금율보 2.pdf |
|---|---|---|
| 쪽수 / 용량 | 262쪽 / 43 MB | 240쪽 / 28 MB |
| 형태 | 스캔 이미지만 (텍스트·목차 북마크 없음) | 동일 |
| 해상도 | 표지 2481×3510 JPEG, 본문 4963×7020 PNG(약 600dpi) | 본문 4963×7020 PNG |
| 앞부분 | p1–4 표지(컬러·흑백 중복), p5–11 머리말·대금 설명·분류·운지법, p12–13 목차, p14–16 악상기호·장식음 | p1–7 머리말~운지법, p8–9 목차, p10–12 악상기호 |
| 본문 시작 | p17 = 인쇄 쪽 11 | p13 = 인쇄 쪽 11 |
| 쪽 번호 | **PDF 쪽 = 인쇄 쪽 + 6** (p17→11, p121→115, p260→254) | **PDF 쪽 = 인쇄 쪽 + 2** (p13→11, p24→22, p240→238) |
| 마지막 인쇄 쪽 | 254 | 238 |
| 상태 | 인쇄본(악보는 전부 인쇄 활자). 2권보다 선이 약간 흐림. 드물게 펜 낙서(p121 `Gm` 3곳) — 악보 아님, 무시 | 깨끗한 인쇄본 |

- 두 권은 **같은 책의 다른 판**이다. 곡은 대부분 겹치지만 배치가 다르다(인쇄 쪽 22: 1권 = 엄마야 누나야·산도깨비, 2권 = 소금장수). 1권은 뒤쪽에 곡이 더 있다(인쇄 239–254, 트로트·가요류).
- 목차는 3단 × 약 50행, 2쪽. **S0 결과(10-10): 2권 294곡, 1권 321곡 → 합쳐 412행**(버전 포함, 2권 채택 304 + 1권 전용 108). 2권에만 있는 곡 74.
- **1권과 2권은 쪽 배치가 전혀 다르다**(같은 곡도 쪽 번호가 다름. 예: 강강술래 2권 125 / 1권 148). 위 "인쇄 쪽 22" 비교는 우연.
- 율명은 **인쇄 활자**(민요채보 같은 손글씨 아님). 주로 청성(潢 汰 㴌 淋 湳 㳞)·중성.

### 한 쪽의 곡 배치 (여러 곡이 한 쪽에 있음)

| 유형 | 예 | 설명 |
|---|---|---|
| A. 1쪽 1곡 | 2권 p24 소금장수 | 쪽 전체가 한 곡. 위에 제목·장단(잦은모리)·구간(노래/전주) |
| B. 가로로 여러 곡 | 2권 p13 (어린송아지·탄일종·개나리·비행기·학교종 5곡) | 곡마다 별도 테두리, 제목은 위 가로쓰기 |
| C. 위/아래 2곡 | 2권 p16 (바다 / 기다리는 마음) | 쪽 가운데 가로 구분선, 제목은 오른쪽 세로쓰기 |
| D. 혼합 | 1권 p241 (가슴아프게 / 그리움은 가슴마다) 등 | 제목 + `□=70` 빠르기, 테두리가 붙어 있음 |

- 한 곡의 기본 단위는 **줄 = 율명 칸 + 바로 오른쪽 가사 칸** 한 쌍, 오른쪽 줄부터 읽는다. 줄 길이는 대부분 16정간(2권 쪽 11·22에서 확인). 반쪽 곡의 정간 수는 곡마다 S1 에서 기록.
- 기타 표기: 장단명(굿거리·잦은모리…), `□=60` 빠르기, `노래`·`전주`·`1절/2절` 구간, `fine`, `D.S`, 시김새(㇂ 모양 꺾음 `ㄱ`·`ㄴ`, 요성 물결 등), 숫자 첨자(`淋1`).

### 자동 분할 시험 결과

OpenCV 로 긴 세로·가로선을 찾아 테두리 박스를 구했다.
- 2권 p13: 5곡 중 4곡 박스 정상, 1곡은 두 박스로 쪼개짐. p24: 1박스 정상. p16: 박스 3개가 겹침.
- 1권 p17: 0개(선이 흐려 실패). 1권 p241: 7개로 조각남.

→ **완전 자동 분할은 불가.** 자동 후보 + 사람(또는 AI 시각 판독)이 확정하는 반자동 방식으로 간다.

## 2. 산출물

```
sheets/대금율보/
  csv/{분류}/{곡명}.csv   ← 앱 목록에 올라가는 것 (정간보 CSV v2, 분류 = 카테고리 → 7절)
  원본/{권}_{인쇄쪽}_{순번}.png   ← 곡별 crop 이미지 (CSV `원본` 행이 가리킴)
  검수/{곡명}.xlsx, _목록.xlsx
  _작업/
    추출설계서.md (이 문서), 판독규격.md (민요 규격 + 4절 추가 규칙)
    목차.tsv              ← S0
    pages/{권}_{PDF쪽}.json  ← S1 곡 영역 지도
    tsv/{곡ID}.tsv        ← S3 판독 결과
    도구/ (split_pages.py, crop_songs.py, build.py …)
```

- `generate_sheets_index.py` 는 `sheets/<카테고리>/csv/*.csv` 만 읽고 CSV 가 없는 카테고리는 건너뛰므로, 작업 중에는 앱에 아무것도 나타나지 않는다.
- 그룹 `대금율보` 안에 분류별 카테고리(`csv/{분류}/`, 1·2권 섞음). 기존 민요는 별도 그룹 → 결정 1, 7절.

## 3. 파이프라인

```
S0 목차 → 곡 목록  →  S1 쪽별 곡 영역 지도  →  S2 곡별 crop  →  S3 판독(TSV)
   →  S4 build(CSV·검수 xlsx)  →  S5 사람 검수  →  S6 index 생성·push
```

### S0. 곡 목록 (`_작업/목차.tsv`)

두 권의 목차를 판독해 하나로 합친다.

```
곡ID	곡명	2권_인쇄쪽	1권_인쇄쪽	채택	분류	비고
b2_011_1	어린송아지	11	11	2권	동요
b2_047_1	사랑가	47	…	2권	민요	목차 "47,148" → 버전 2개
b1_239_1	…		239	1권	가요	2권에 없음
```

- **채택 규칙: 2권 우선, 2권에 없는 곡만 1권. 단 같은 곡이라도 내용이 다르면 1권 것도 올린다(결정 4).** 두 권 모두 인쇄본이라 품질 차이는 작다(1권 선이 약간 흐림). 1권의 드문 펜 낙서는 악보가 아니므로 판독하지 않는다.
- 곡ID = `{권}_{인쇄쪽 3자리}_{쪽 안 순번}`. 쪽 안 순번은 오른쪽 위 → 왼쪽, 위 → 아래.
- 같은 이름의 곡이 여러 개면 CSV 파일명에 `(2)` 또는 장단을 붙인다(`사랑가 (중모리).csv`).

**S0 결과 (2026-10-10)** — `목차_2권.tsv`·`목차_1권.tsv`(목차 그대로 판독) → `도구/make_toc.py` → `목차.tsv` 412행.
- 같은 곡 판별 = 공백·`中` 뺀 곡명 일치 + 별칭(`엽불승`=`염불승`). 버전이 여러 개면 쪽 순서로 짝지음(예: 강원도 아리랑 2권 90,91 ↔ 1권 21,109 / 1권 115 는 1권 전용 버전).
- **곡ID 순번은 임시**(쪽 안 가나다 순). S1 에서 위치 순으로 다시 매기고 목차.tsv 를 고친다. `분류` 는 S1 에서 본문 보고 채운다(목차는 가나다 순이라 분류 정보 없음).
- S1 에서 확인할 것: 목차 제목이 잘린 곡(`어화둥둥 우리사랑` `저녁무렵부터 새벽이` `주여 우리를 불쌍히` `티끌같은 세상 이슬같은`), 표기 의심(`빨가장이` `모녀키타` `늴리리야`), 이름이 달라 짝이 안 지어진 곡 후보(2권 `방아타령` 120,134 ↔ 1권 `경기 방아타령`·`남도 방아 타령`, 2권 `질음시조` 등). 짝이 틀리면 ALIAS 에 넣고 다시 돌린다.

### S1. 쪽별 곡 영역 지도 (`_작업/pages/b2_013.json`)

```json
{
  "book": 2, "pdfPage": 13, "printedPage": 11,
  "songs": [
    {
      "id": "b2_011_1", "title": "학교종",
      "titleBox": [0.80, 0.11, 0.10, 0.03],
      "parts": [ { "box": [0.736, 0.145, 0.151, 0.745], "lines": 2, "rows": 16 } ],
      "beat": "4/4", "jangdan": "", "tempo": "", "sections": [],
      "continuesFrom": null, "continuesTo": null
    }
  ]
}
```

- 좌표는 쪽 크기 대비 0~1 (기존 `book/*/*.json` 그리드 좌표와 같은 방식).
- `parts`: 한 곡이 여러 영역(위 단 → 아래 단, 다음 쪽)에 이어지면 **읽는 순서대로** 나열. 쪽을 넘기면 `continuesTo` 로 다음 쪽 지도와 잇는다.
- `lines` = 율명 줄 수, `rows` = 한 줄의 정간 수(S3 행 수 검사에 쓴다).
- 도구 `split_pages.py`: 2절 OpenCV 박스 검출로 초안 JSON 을 만들고, 확정 전에 쪽 이미지 위에 박스·곡ID 를 그린 **확인용 이미지**를 출력한다. 확정은 저해상도(약 100dpi) 쪽 이미지를 보면서 사람/AI 가 JSON 을 고친다.
- 검사: 지도에 있는 곡 = 목차의 그 쪽 곡(S0)과 일치해야 한다. 목차에 없는 곡이 나오면 목차.tsv 에 추가.

### S2. 곡별 crop (`crop_songs.py`)

- `parts` 를 300dpi 로 잘라 한 장으로 잇는다(위 단 → 아래 단을 세로로). 제목·빠르기 영역도 포함.
- 판독용으로 줄 4개 단위 조각(`_RT` 처럼)도 만든다 — 민요 작업에서 이미지 한 변이 2000px 를 넘으면 세션이 멈춘 문제가 있었다.
- `원본/` 에는 곡별 이어붙인 이미지만 커밋한다(검수 때 원본 대조용). 판독용 조각은 저장소 밖(`/tmp/dg_pan`)에 둔다.

### S3. 판독 (`_작업/tsv/{곡ID}.tsv`)

**민요 `판독규격.md`(TSV v2)를 그대로 쓴다.** 머리 정보 `#원본` = S2 crop, 본문 행 수 = 줄수 × 행수. 추가 규칙은 4절.

- 1곡씩 sub-agent 판독 → 다른 sub-agent 가 crop 과 대조 검수(민요 10-08 방식).
- 첫 10곡(유형 A~D 섞어서)을 시범으로 하고 4절 규칙을 확정한 뒤 나머지를 진행한다.

### S4. build

- 민요 `build_all.py` 를 복사해 `_작업/도구/build.py` 로 만든다. TSV → CSV v2 + 검수 xlsx + `_목록.xlsx`.
- **이미 검수 xlsx 가 있는 곡은 덮어쓰지 않는다**(민요 10-08 강강술래 사고 재발 방지). `--force {곡ID}` 일 때만 다시 만든다.
- 검사: `generate_sheets_index.py --check` 오류 0, 팔레트 외 글자는 `?` 만 허용.
- 민요 도구(`build_all.py`, `xlsx_to_csv.py`)는 표준 라이브러리만으로 xlsx 를 읽고 쓴다(openpyxl 불필요). 이 iMac 에서 민요 검수 xlsx 88개를 만든 그 도구를 그대로 쓴다.

### S5. 검수 · S6. 반영

- 민요와 같은 `검수반영.sh` 방식(검수 xlsx → csv 재생성 → index → commit/push). CSV `상태` 행: `초안` → `검수완료`.
- 초안도 바로 노출한다(결정 2). 앱 목록에 `초안` 배지 표시(7-4).

## 4. 원본 → 앱 매핑 (판독규격 추가 규칙)

### 4-1. 칸 배치

| 원본 | 앱(CSV v2) |
|---|---|
| 오른쪽 첫 줄의 율명 칸 / 가사 칸 | 1열(대) / 1열(소) |
| n번째 줄 | n열. 앱 1페이지 = 10줄 |
| 11줄 이상 | 페이지 2, 3 … 로 이어서 (`페이지,N` 블록) |
| 한 줄 16정간 | `박자,4/4박자` `행수,16` |
| 한 줄 12정간 | `3/4박자`, 12 |
| 한 줄 8정간 등 그 밖 | 2/4·16 등 가장 가까운 것 + `메모` 에 실제 구조. 반쪽 곡이 8정간이면 두 줄을 이어 16정간 한 줄로 합치지 **않는다**(원본 줄 = 앱 열 유지) |
| 한 정간에 위→아래 여러 음 | 칸 안 줄바꿈 (TSV 에서는 `\|`) |
| 정간 안 `-潢` 처럼 연음+율명 | `―` 와 율명을 원본 순서대로 (`潢\|―潢` → 판독규격 그대로) |

### 4-2. 머리 정보 (CSV 정보 행)

```
형식,정간보CSV,2
타이틀,소금장수
박자,4/4박자
행수,16
장단,잦은모리          ← 원본 표기 그대로 (없으면 행 생략)
빠르기,□=60
구간,1-8:노래 9-10:전주  ← 줄 번호 기준. 노래/전주/1절/2절 표시
반복,fine 3줄 16정간 / D.S 7줄
출처,2권 22쪽            ← 인쇄 쪽. 책 이름(대금율보)은 쓰지 않는다 (8절)
원본,b2_022_1.png        ← sheets/대금율보/원본/ 기준
상태,초안
```

- 앱은 모르는 정보 행을 `extras` 로 보존하므로 장단·빠르기·구간·반복은 정보 행으로만 둔다(반복 재생은 앱 기능 밖).
- 구간 순서는 바꾸지 않는다. 원본이 오른쪽 → 왼쪽으로 적은 순서 그대로.

### 4-3. 기호

**악상기호 쪽 판독 완료(2026-10-10, 2권 p10–12 = 1권 p14–16, 두 권 내용 같음).** 책은 기호 3종을 정의한다. 거의 전부가 앱 악상기호 카탈로그(`sigimsae/악상기호.json`, 2021 대금정악보 기준 60개)에 같은 이름·같은 전개로 이미 있다. 문제는 **정간보 만들기 팔레트(`JeongganSymbols.MARKS` 16개)에는 일부만 있다**는 것.

| 책 기호 (이름) | 책 정의 | 카탈로그 id · glyph | 지금 팔레트 |
|---|---|---|---|
| **악상기호** | | | |
| `<` 숨표 | 숨 짧게 | sumpyo `<` | `‹` (뜻 다름: 정간 경계 표시) |
| `△` 쉼표 | 시가만큼 쉼 | swimpyo `△` | `△` |
| `▼` 끊는표 | 짧게 끊음 | kkeunneunpyo `▾` | 없음 |
| `⌇` 요성 | 흔들어 냄 | yoseongpyo / nongeumpyo | 없음 |
| `ㅂ` 늘임표 | 두 배 정도 늘임 | neurimpyo | 없음 |
| `)` 흘림표 / `(` 미는표 | 흘려 내림 / 밀어 올림 | heullimpyo / mineunpyo | 없음 |
| `∨` 특강표 | 그 음만 강하게 | teukgangpyo `∨` | 없음 (`^` 는 다른 뜻) |
| `ㅣ` `·` 덧길이·반길이표 | 시가 가감 | deotgiripyo / bangiripyo | `·` |

## 5. 작업량·순서

1. S0 목차 2권 판독 + 1권 대조 → `목차.tsv` (곡 수 확정)
2. 악상기호 쪽 판독 → 4-3 표 확정
3. 도구 3개(`split_pages.py`, `crop_songs.py`, `build.py`) 작성
4. 시범 10곡 S1~S5 → 규칙 수정
5. 나머지: 2권 본문 228쪽 → 1권 전용 곡. 곡 단위로 진행 이력(`진행이력.md`)에 기록

판독은 곡당 줄수 × 행수 칸을 모두 적어야 하므로(평균 6줄 × 16 ≈ 100칸) 곡 수 240 기준 2만 칸 이상이다. 하루 단위로 쪽 범위를 정해 나눈다.

## 6. 결정 사항 (2026-10-10 사용자 결정)

1. **카테고리: 분류별로 나눈다.** 1권·2권은 섞어서 장르로 나누고, 기존 민요(민요채보 87곡)는 **별도 그룹**으로 둔다 → 7절.
2. **검수 전 초안 CSV 도 앱에 노출한다.** (`상태,초안` 그대로 push. 앱 목록에 `초안` 표시 → 7절)
3. **기호: (a) 앱 팔레트를 악상기호 카탈로그 glyph 로 넓힌다.** 앱(JeongGanView) 수정·배포 필요. `generate_sheets_index.py` 의 KNOWN 에 CATALOG_MARKS 를 더한 것(미커밋)은 이 결정과 맞음.
4. **1권·2권에 같은 곡이 있고 내용이 다르면 둘 다 올린다.** S1 에서 짝지은 곡(목차.tsv 227쌍)을 두 권 본문으로 비교(장단·줄 수·정간 수·첫 줄 율명) → 다르면 1권 것도 별도 행으로 추가, 파일명 `곡명 (1권).csv`.
5. **저작권: 상관없이 올린다**(가요·트로트 포함, 사용자 판단).

## 7. 정간보 만들기 '불러오기' 화면 — 민요와 대금율보 구분 (설계)

### 7-1. 현재

- `JeongganMakerScreen.kt` 원격 시트 다이얼로그: `sheets-index.json` 의 모든 카테고리 파일을 **구분 없이 한 목록**으로 늘어놓는다. 제목은 `📋 [민요] 87곡` 처럼 카테고리 이름을 이어 붙임. 검색 없음.
- 대금율보가 들어오면 약 500곡이 한 목록에 섞이고, 제목 줄도 카테고리 10개 가까이 이어져 넘친다.

### 7-2. 구조: 그룹 › 카테고리 2단

| 그룹 (출처) | 카테고리 | 저장소 폴더 |
|---|---|---|
| **민요** (민요채보, 기존) | 민요 | `sheets/민요/csv/*.csv` — **그대로** (URL·앱 캐시 유지) |
| **대금 악보** (폴더 `대금율보`, 1·2권 섞음) | 동요·쉬운곡 / 찬불가 / 민요 / 정악 / 시조·가사 / 산조·시나위 / 가요 / 외국곡·창작곡 | `sheets/대금율보/csv/{분류}/*.csv` |

- 그룹 = `sheets/` 바로 아래 폴더, 카테고리 = 그 안 `csv/` 의 하위 폴더(없으면 `csv/` 자체가 카테고리 하나). 기존 민요는 하위 폴더가 없으므로 그룹 민요 = 카테고리 민요 하나.
- 대금율보에도 장르 `민요` 가 있지만 그룹이 달라 섞이지 않는다(화면에 `대금율보 › 민요`).
- 분류 이름·순서는 S1 에서 `목차.tsv` `분류` 칸을 채우며 확정(위 8개는 쪽 배치로 추정한 안).

### 7-3. sheets-index.json (하위 호환 확장)

```json
{
  "version": 1,
  "groups": [ {"name": "민요"}, {"name": "대금 악보"} ],
  "categories": [
    { "name": "민요", "group": "민요", "label": "민요", "files": [ … ] },
    { "name": "민요 (대금 악보)", "group": "대금 악보", "label": "민요",
      "files": [ { "name": "강강술래", "title": "강강술래", …, "beat": "4/4", "rows": 16, "pages": 1,
                   "status": "판독 초안(검수 전)", "source": "2권 125쪽", "sha256": "…" } ] }
  ]
}
```

- 추가 필드: 루트 `groups`(표시 순서), 카테고리 `group`·`label`, 파일 `status`(CSV `상태` 행)·`source`(CSV `출처` 행).
- `name` 은 전체에서 유일하게(`대금율보-민요`) → **구버전 앱**은 새 필드를 무시하고 지금처럼 평평한 목록으로 보여 준다(깨지지 않음).
- `generate_sheets_index.py`: `csv/` 하위 폴더 스캔 + 위 필드 생성. 기존 민요 항목의 path·url·sha256 은 바뀌지 않는다.

### 7-4. 화면

```
┌ 📋 시트 불러오기 · 499곡                     ⟳ ┐
│ [ 민요 87 ] [ 대금율보 412 ]          ← 그룹 탭 │
│ (전체)(동요·쉬운곡)(민요)(정악)(시조·가사)…  ← 카테고리 칩 (대금율보만) │
│ 🔍 곡명 검색                                     │
│ ── 민요 ──────────────────────  ← '전체' 일 때 카테고리 머리글 │
│  강강술래            4/4 16행   2권 125쪽 [초안] │
│  강원도 아리랑 (1권)  2/4 16행   1권 115쪽 [초안] │
└──────────────────────────────────────── 닫기 ┘
```

- **그룹 탭**: 민요 / 대금율보. 곡 수 표시. 마지막 선택 그룹·카테고리를 SharedPreferences 에 저장해 다음에 그대로 연다.
- **카테고리 칩**: 그룹 안 카테고리가 2개 이상일 때만 표시(민요 그룹은 숨김). `전체` 는 카테고리 머리글(sticky header)로 나눠 보여 준다.
- **검색**: NFC·공백·대소문자 무시 부분 일치(`StaffSamples.kt`·`EnsembleCatalog.kt` 방식). 검색어가 있으면 **모든 그룹**에서 찾고 결과 줄에 `대금율보 › 민요` 처럼 위치를 붙인다. 같은 곡이 민요채보·대금율보 양쪽에 있으면 둘 다 나온다.
- **목록 줄**: 제목 / 박자·행수·페이지 / 출처(`2권 125쪽`, 민요는 생략) / `초안` 배지(`status` 가 `검수완료` 가 아니면).
- 제목 줄은 카테고리 이름 나열 대신 `📋 시트 불러오기 · N곡`.
- 새 필드가 없는 index(구버전 index)를 받으면 group = name 으로 처리 → 지금과 같은 동작.

## 8. '대금율보' 이름은 앱에 내보내지 않는다 (2026-10-10 사용자 지시)

- `대금율보` 는 저장소 관리용 이름(폴더 `sheets/대금율보/`, `book/대금율보/`, 곡ID, _작업 문서)이다.
