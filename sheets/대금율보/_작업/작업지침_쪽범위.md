80장이 넘으면 지금 곡 TSV 를 마무리하고 멈춘 뒤 남은 쪽·곡을 보고한다. 쪽 하나는 **지도 → crop → 그 쪽 곡 판독** 까지 끝내고 다음 쪽으로 간다.

## 0. 기준 예시 (먼저 볼 것)

- 판독: `tsv/b2_011_1.tsv`(단순), `tsv/b2_022_1.tsv`(꾸밈 부호 ㄴ ㄱ, ʒ フ), `tsv/b2_229_1.tsv`(한 정간 여러 음)
- 판독 TSV 만드는 법: `도구/예시_시범10곡.py` (mk 호출 예시 — 실행하지 말 것). 새 곡은 `도구/mk_tsv.py` 의 `mk(...)` 로 쓴다.

## 1. 쪽마다 (네 범위의 PDF 쪽 하나씩)

1. `python3 split_pages.py grid b2_045` → `/tmp/dg_pan/show/b2_045.png` 를 이미지로 본다(0.05 눈금). 쪽 표기 `b{권}_{PDF쪽 3자리}`.
   PDF 쪽 = 인쇄 쪽 + 2 (2권), + 6 (1권).
2. 곡 경계 찾기. 세로선 위치는 `python3 lines.py 2 45 0.2 0.8` (권, PDF쪽, y0, y1 → 긴 세로선 x 목록), 가로선은 `python3 lines.py 2 45 0.4 0.6 h` (x0, x1 → y 목록). 선이 흐리면 `T=0.3 python3 lines.py …`.
   - 율명 칸(넓음) + 가사 칸(좁음) = 한 줄. 줄 수 = lines. 한 줄의 정간 수 = rows (16 또는 12가 대부분; 가로선 개수로 확인).
3. `pages/b2_045.json` 작성 (형식은 예시와 같게, `"confirmed": true`).
   - 곡ID = `b{권}_{인쇄쪽 3자리}_{순번}`, 순번은 쪽 안 위치 순(위 단 먼저, 단 안에서는 오른쪽 → 왼쪽). 1부터.
   - box = [x, y, w, h] 쪽 대비 0~1, 율명·가사 칸 전체를 감싸게(제목은 빼고). 위 제목이 가로쓰기면 `titleBox` 도.
   - 필드: `title`(본문 제목 그대로), `beat`, `jangdan`(굿거리·세마치·잦은모리 … 원본 표기), `tempo`(`♩=60` 등), `sections`, `repeat`, `memo`,
     **`genre`** (아래 분류 중 하나, 필수), `parts[].lines`, `parts[].rows`.
   - 분류: `동요·쉬운곡` `찬불가` `찬송가·성가` `민요` `정악` `시조·가사` `산조·시나위` `가요` `외국곡·창작곡`. 애매하면 가장 가까운 것 + memo.
   - 한 곡이 위 단 → 아래 단처럼 여러 영역이면 parts 를 읽는 순서대로. **다음 쪽으로 이어지면** 다음 쪽 part 에 `"pdfPage": 46` 을 적어 같은 곡에 넣는다(다음 쪽이 네 범위 밖이어도). 
     **네 범위 첫 쪽이 앞 쪽 곡의 이어짐으로 시작하면 그 부분은 지도에 넣지 않는다**(앞 범위 담당). 그 쪽 지도 memo 에 `앞 쪽 곡 이어짐 x0~x1` 이라고만 적는다. 이어짐뿐인 쪽은 `"songs": []` 로 지도를 만든다.
   - 1권 쪽은 **배정 목록에 적힌 곡만** 지도에 넣는다(나머지는 2권에서 처리됨). 쪽 memo 에 넣지 않은 곡 이름을 적는다.
   - 악보가 아닌 쪽(목차·설명·빈 쪽)은 `"songs": []` + memo.
4. `python3 split_pages.py show b2_045` 로 박스를 확인(이미지 보기). 틀리면 고친다.
5. `python3 crop_songs.py b2_043_1 b2_043_2 …` (그 쪽 곡ID들) → 판독 조각 `/tmp/dg_pan/{곡ID}/t*.png`. 박스를 고쳤으면 `--force`.

## 2. 판독 (곡마다)

- `/tmp/dg_pan/{곡ID}/` 의 `t{part}_{k}.png` 를 **전부** 이미지로 보고 읽는다. k=1 이 가장 오른쪽 줄들. full.png 는 배치 확인용(글자 읽기에 쓰지 말 것).
- `python3 -c` 또는 임시 스크립트에서 `sys.path.insert(0, "도구 경로"); from mk_tsv import mk; mk(...)`. 줄 번호는 parts 순서대로 이어서(part1 의 줄 → part2 의 줄).
- 규칙 (예시 TSV 와 같게)
  - 칸 안 위→아래: `潢|―潢` 식. 정간 맨 아래 쉼 `△`, 앞 칸에서 이어지는 연음 `―`.
  - 율명 아래 `―` 와 꾸밈 부호(ㄴ ㄱ ㄷ И 등): `淋|―|ㄴ` 처럼 원본 위치 그대로.
  - 율명 오른쪽에 붙은 꾸밈음(ʒ フ ∧ ㅅ 등)은 율명에 붙여 쓴다 `潢ʒ`. 정간 경계 숨표 `<` → `‹`.
  - 기호는 `추출설계서.md` 4-3 표의 카탈로그 glyph 만. 모르는 모양은 `?` + 비고에 모양 설명.
  - 율명 60자 표(판독규격.md)만 쓴다. 인쇄 활자라 획이 분명함: 潢 汰 㴌 淋 湳 潕 㳞 浹 등 청성이 많다. `汏`(氵大)·`汰`(氵太) 구별.
  - 숫자 첨자(`淋1`)는 율명만 적고 비고.
  - 가사: 율명 줄 바로 오른쪽 가사 칸, 그 정간 높이에서 시작하는 글자. 2절 가사가 있으면 1절만 가사 칸에, 2절은 memo 에 짧게.
  - 빈 정간도 칸을 비워 두면 된다(mk 가 줄수×행수 행을 다 쓴다).
- 판독 포기 금지. 정간마다 가장 그럴듯하게, 정말 모르는 글자만 `?`.

## 3. 끝나면

- `python3 split_pages.py check` 오류 중 **네 쪽** 것이 없게(목차.tsv 에 곡ID 가 없다는 오류는 무시 — 나중에 맞춘다).
- `python3 build.py --dry` 실행해서 네 곡의 `[형식]` `[중복]` 문제가 없는지 본다(`--dry` 는 파일을 안 쓴다; `--dry` 없이 실행하지 말 것).
- 마지막 답: 쪽별 곡ID·제목·분류·줄×정간 표, 확신 없는 곡, 문제점. 짧게.
